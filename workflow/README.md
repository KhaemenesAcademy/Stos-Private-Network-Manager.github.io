# Workflow · Dated Journal

Use `workflow/logs/YYYY/MM/YYYY-MM-DD-topic.md` for dated **audits, tests, repairs, upgrades, Codex updates, decisions, and follow-ups**. `INDEX.md` registers entries; `templates/SESSION_LOG_TEMPLATE.md` provides the format. Entries must cite files, commits and actual test evidence, distinguish proposed work from verified results, and avoid learner data, passwords, tokens, confidential keys or private exports. A summary is not a verbatim transcript. A log does not deploy a change.
